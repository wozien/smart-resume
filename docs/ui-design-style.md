# Admin Dashboard UI

- **id:** `admin-dashboard-ui`
- **别名:** 管理后台 UI, 数据仪表盘, Admin Dashboard, 运营后台, 分析看板
- **一句话:** 彩色数据。清晰层级。为天天待在里面而建。
- **适用:**
  - SaaS 分析与报表仪表盘
  - 电商管理后台
  - 项目管理工具
  - CRM 与运营仪表盘
  - 任何数据可视化是核心体验的产品
- **避免:**
  - 简单单页营销站点
  - 没有数据可展示的面向消费者应用
  - 只有一个主操作的产品
  - 内容优先或编辑型产品
- **来源:** https://uidesignprompts.com/prompts/admin-dashboard-ui

## Prompt

## 管理后台 UI 设计系统

### 气质

鲜明、数据优先、毫不费力地扫读。这种仪表盘风格把每个指标都当作值得看清楚的东西——渐变填充卡片、带悬停交互的真实图表，以及颜色编码拆解，取代通用后台模板的扁平灰盒子。它感觉活着但不吵：每种颜色选择都映射到具体数据含义，布局从不牺牲清晰去换装饰。

### 核心布局架构

三区外壳，可选第四「图标轨」：

1. **图标轨**（可选，56px，最左）：顶层应用切换图标，无标签
2. **侧栏**（240px，可折叠到 64px）：带分区标签的分组导航
3. **导航栏**（顶部，64px，粘性）：搜索、通知、个人资料
4. **主内容**（剩余空间，可滚动）：指标卡、图表、表格、列表

### 色彩系统

- 页面背景：`#F6F7FB` — 柔蓝灰，永不用纯白
- 侧栏：`#FFFFFF` 或 `#F9FAFC` — 几乎与页面齐平，仅用 1px 边框分隔
- 卡片表面：`#FFFFFF`
- 边框：`#E7E9F3` — 唯一边框色，到处用 1px
- 主文字：`#14152B` — 带蓝底的近黑
- 次文字：`#565A78`
- 弱化文字：`#8C8FA8`
- 品牌靛蓝：`#5A6ACF` — 主操作、激活导航、主图表系列
- 品牌紫罗兰：`#8B5CF6` — 次强调、渐变配对伙伴、次图表系列
- 成功绿：`#12B76A` / 背景 `#E7FAF0` / 文字 `#027A48`
- 警告琥珀：`#F79009` / 背景 `#FFFAEB` / 文字 `#B54708`
- 错误红：`#F04438` / 背景 `#FEF3F2` / 文字 `#B42318`
- 中性灰：背景 `#F2F4F7` / 文字 `#475467`

### 指标卡渐变系统（标志性元素）

与扁平白色指标卡不同，本系统使用两种卡片处理，在同一行混用以形成视觉节奏：

**渐变英雄卡**（每行最多 1 张，用于最重要指标）：

```css
background: linear-gradient(135deg, [color-1] 0%, [color-2] 100%);
color: white;
border-radius: 16px;
padding: 22px 24px;
```

轮换的渐变对：靛蓝→紫罗兰（`#5A6ACF → #8B5CF6`）、青绿→绿（`#0D9488 → #22C55E`）、橙→琥珀（`#EA580C → #F59E0B`）、粉→玫红（`#DB2777 → #F43F5E`）。白字，圆形图标按钮（右上，`rgba(255,255,255,0.15)` 背景）用于「查看更多」，数值 30px 粗白，标签 `rgba(255,255,255,0.85)`。

**扁平数据卡**（同一行另外 3 张）：

```css
background: white;
border: 1px solid #e7e9f3;
border-radius: 16px;
padding: 20px 22px;
```

顶行：小图标（36px，着色背景匹配分类色）+ 趋势徽章（胶囊，绿/红）。数值 26-28px 粗深色文字。下方标签弱化 13px。可选极小行内 sparkline 或 1 行对比（「↑ 12% from last month」）。

### 图表组件 — 真实数据可视化

**柱状图（分组/对比）：**

- SVG 或基于 CSS 的垂直柱，两系列并排（例如「Revenue」vs「Gross Margin」）
- 柱颜色：靛蓝 `#5A6ACF` + 琥珀 `#F59E0B`，或单品牌图用靛蓝 + 紫罗兰
- 柱圆角：仅顶部 4px
- X 轴标签在下方，11px 弱化文字
- Y 轴网格线：1px `#F0F1F7`，仅水平
- **悬停 tooltip**：浮动卡片出现在悬停柱对上方，显示精确值 + 趋势，`background: #14152B`，白字，`border-radius: 8px`，小三角指针
- 图例：彩色点 + 标签对，在图表上方右上或左上

**半圆环仪表（单个 KPI）：**

- SVG 弧，180° 扫掠，3-4 个颜色段表示一个总量的子类别
- 粗描边（18-24px），圆线帽
- 中心标签：大号粗数值 + 小号弱化副标签，位于弧下方平坦空间
- 下方图例：每段彩色点 + 分类名

**完整圆环（拆解图）：**

- 由多个 `stroke-dasharray` 段组成的 SVG 圆，4-8 个分类
- 60-70% 内半径（粗环，不是细环）
- 中心文字：总量粗体 + 「Total X」弱化标签
- 侧方或下方图例：点 + 标签 + 百分比，每段一行，按大小降序

**迷你 Sparkline（嵌在扁平卡内）：**

- 极小 SVG 折线或面积图，宽 60-80px，高 24-32px
- 无轴、无标签 — 纯趋势形状
- 颜色匹配卡片分类色，线下低不透明度填充面积

**圆形进度环（单指标，头像风格）：**

- SVG 圆，粗描边，单色，圆帽
- 用于展示一个比率（例如「88% reached」），常包裹头像照片或图标
- 百分比和标签居中

### 侧栏规则

- 宽度：展开 240px，折叠 64px
- 背景：`#FFFFFF`，`border-right: 1px solid #E7E9F3`
- 可选图标轨在主侧栏左侧：宽 56px，独立背景 `#F6F7FB`，应用切换图标垂直堆叠，无文字标签，激活图标获得彩色圆角方形背景
- Logo 区：顶部，高 64px，底部分割线，图标标记（圆角方形，品牌渐变）+ 字标
- 分区标签：11px 大写，letter-spacing 0.08em，颜色弱化，margin `20px 0 8px`，例如「OVERVIEW」、「MARKETING」、「PAYMENTS」、「SYSTEM」
- 导航项：图标（18px）+ 标签，padding `9px 14px`，border-radius 8px，margin `0 12px`
- 激活状态：`background: #EEF0FF`，`color: #5A6ACF`，图标匹配，font-weight 600 — 使用填充胶囊激活状态时不需要左边框（比边框方案更干净）
- 悬停（未激活）：`background: #F6F7FB`
- 导航项徽章（例如未读数）：小胶囊，品牌色背景，白字，右对齐
- 侧栏底部：用户资料行（头像 + 姓名 + 角色）+ 折叠切换 + 深色模式开关（可选）
- 子项（可展开组如「Tracking」）：chevron-down 图标，子项缩进 14px

### 导航栏规则

- 高度：64px，`background: white`，`border-bottom: 1px solid #E7E9F3`，顶部粘性
- 左：页面标题（20px 粗）或搜索优先产品的搜索栏
- 搜索栏：`background: #F6F7FB`，`border-radius: 10px`，高 40px，图标在左，占位弱化，可选 `⌘F` kbd 徽章在内部右对齐
- 右：图标按钮（邮件、带红点的铃、设置）各 38px 圆/方，悬停背景 `#F6F7FB`，分割 `1px` 线，然后用户块（头像 36px + 姓名 + 邮箱堆叠，13px/11px）
- 可选导航区主操作按钮（例如「+ Add Project」实心，「Import Data」描边），当页面需要明确顶层操作时

### 英雄横幅卡（可选，用于内容驱动仪表盘）

- 全宽卡跨越内容行的 60-70%，剩余 30-40% 配一个统计控件
- 背景：大胆渐变（例如 `linear-gradient(135deg, #6D5BD0 0%, #8B5CF6 100%)`）
- 装饰：角落低不透明度的微妙抽象形状或星爆/闪光图标
- 眉题标签：小号大写胶囊或纯文字，`rgba(255,255,255,0.7)`
- 标题：22-26px 粗白，最多 2 行
- CTA 按钮：白或近黑胶囊按钮带图标，在渐变上高对比
- 克制使用 — 每个仪表盘一张英雄横幅，通常只在「home」或「overview」页，不在数据密集子页

### 列表组件

**活动 / 协作列表：**

- 行：头像（36px 圆）+ 姓名（14px weight 600）+ 描述（13px 弱化）+ 状态胶囊（右对齐）
- 状态胶囊颜色：Completed（绿）、In Progress（琥珀）、Pending（灰）
- 分割：行间 1px 边框，最后一行无边框
- 卡片页头右上「Add Member」/「+New」按钮

**排名/国家列表（带旗帜或图标 + 趋势）：**

- 行：小图标/旗帜（20px）+ 标签（14px）+ 数值（14px weight 600）+ 趋势箭头（绿上 / 红下）+ 百分比
- 用于「Sales by Country」、「Top Products」、排行榜
- 数字列右对齐，小数对齐一致

**快捷入口磁贴：**

- 卡片内的小彩色圆角矩形磁贴（不是完整卡片），每行 2-3 个
- 每个磁贴：实心明亮背景（渐变对颜色之一），图标左上，标签 + 数值堆叠，白字
- 用于「Current Projects」、「Project Finance」、「Our Clients」等快捷入口

### 数据表规则

- 容器：白色卡片，`border-radius: 16px`，`overflow: hidden`，1px 边框
- 页头栏：padding `16px 20px`，左标题 + 副标题，右操作按钮/筛选
- `thead`：背景 `#F9FAFC`，`th` padding `12px 16px`，11px 大写弱化，`border-bottom: 1px solid #E7E9F3`
- `td`：padding `13px 16px`，14px，`border-bottom: 1px solid #F1F2F8`
- 行悬停：`background: #FAFBFF`
- 用户单元格：头像（32px）+ 姓名/邮箱堆叠
- 状态徽章：胶囊，12px weight 500 — Active（绿）/ Pending（琥珀）/ Inactive（灰）/ Error（红）
- 行操作：图标按钮，默认 `opacity: 0`，`tr:hover` 时 `opacity: 1`
- 分页：底栏，左「Showing X–Y of Z」，右编号页按钮

### 字体层级

- 字体：Inter, system-ui, sans-serif
- 页面标题：22px，weight 800，letter-spacing -0.02em
- 卡片标题：15-16px，weight 700
- 指标数值（扁平卡）：26-28px，weight 700，letter-spacing -0.02em
- 指标数值（渐变卡）：28-30px，weight 800，白
- 正文：14px，weight 400，line-height 1.6
- 标签/元信息：13px，弱化
- 图表轴标签：11px，弱化，weight 500
- 表头：11-12px，大写，weight 600，letter-spacing 0.05em
- 导航分区标签：11px，大写，weight 700，letter-spacing 0.08em

### 间距系统（8px 基础网格）

- 内容内边距：桌面 28px 32px，移动端 16px
- 卡片内边距：20-24px
- 卡片页头内边距：16px 20px
- 网格间距：标准 16px，紧磁贴网格 12px
- 区块垂直间距：24px

### 阴影

- 卡片：`0 1px 3px rgba(20,21,43,.05), 0 1px 2px rgba(20,21,43,.03)` — 几乎看不见，纵深来自分层而非戏剧
- 渐变英雄卡：`0 8px 24px rgba(91,92,210,.18)` — 匹配渐变色调的彩色阴影，略强
- 下拉/模态：`0 16px 48px rgba(20,21,43,.14)`
- Tooltip（图表悬停）：`0 8px 20px rgba(0,0,0,.25)`

### 响应式行为

- 桌面 >1200px：完整侧栏（240px）+ 若有图标轨，4 列指标网格，图表并排
- 平板 900-1200px：侧栏收到 64px（仅图标），指标网格 → 2 列，图表垂直堆叠
- 移动端 <600px：侧栏藏在汉堡抽屉后，指标网格 → 1 列，搜索收到仅图标，表格水平滚动

### 切勿做

- 不要每行用超过一张渐变英雄卡 — 它必须作为高亮脱颖而出
- 不要在没有清晰图例的情况下用超过 2 个图表颜色系列
- 不要把渐变用到正文或表格背景 — 渐变只保留给英雄卡、横幅和图表填充
- 不要在任何地方用纯黑 `#000000` — `#14152B` 是最深值
- 不要堆超过 2 个侧栏（图标轨 + 主导航） — 第三列导航会造成混乱
- 不要在卡片上用大于 16px 的圆角，或在按钮上用小于 8px 的圆角
- 不要永久显示行操作按钮 — 仅悬停揭示
